# Конфигурационные файлы для принтеров на базе Klipper
В данном репозитории хранятся конфигурационные файлы Klipper для принтеров Z-Bolt.

# 
1) Вид прошивки:
    - KS - KlipperScreen
    - OP - OctoPrint
2) Модель принтера:
    - Limited Plus
    - L32
    - S32
    - S300
    - S300 HT
    - S300 Dual
    - S400
    - S400 HT
    - S400 Dual
3) Модель платы:
    - SKR 1.3
    - SKR 2
    - S6
    - Spider v2.2
    - Spider v2.3
    - Spider v3.0

# Что здесь есть и чего здесь нет

В этом репозитории — **только конфигурация принтеров**: файлы `.cfg` профилей
и сопутствующие `.conf` (Moonraker, KlipperScreen, crowsnest).

Код расширений Klipper, которых нет в апстриме, живёт в репозитории прошивки
[Z-Bolt/klipper](https://github.com/Z-Bolt/klipper):

| Что | Где |
|-----|-----|
| Модули расширений | `klippy/extras/` |
| Документация по ним | `docs/zbolt/` |
| Офлайн-тесты расширений | `test/zbolt/` |

Расширения приезжают на принтер вместе с обновлением прошивки, копировать их
руками не нужно. Профили Dual-моделей ссылаются на них секциями
`[zbolt_toolchanger]`, `[named_probe]`, `[multiplex_heater]`.
